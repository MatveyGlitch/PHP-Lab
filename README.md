# 💻 PHP Lab

**PHP Lab** — учебное веб-приложение, разработанное в рамках лабораторной работы №7 по дисциплине **«Web-программирование»**.

Приложение объединяет 11 практических заданий по PHP и дополнительную фотогалерею.

---

## ✨ Возможности сайта

- рекурсивное возведение числа в степень;
- отображение текущего времени с правильным склонением слов;
- вывод чисел, кратных трём, с помощью цикла `while`;
- определение чётных и нечётных чисел с помощью цикла `do...while`;
- вывод чисел с помощью цикла `for` без использования тела цикла;
- отображение областей и городов из ассоциативного массива;
- фильтрация городов по начальной букве «К»;
- транслитерация русского текста;
- транслитерация текста с заменой пробелов на подчёркивания;
- калькулятор с четырьмя арифметическими операциями;
- загрузка файлов на сервер.

---

## 🖼️ Фотогалерея

- загрузка изображений в форматах JPG, PNG и WEBP с проверкой типа, размера и разрешения;
- автоматическое создание миниатюр с сохранением пропорций;
- хранение оригиналов без изменения качества и разрешения;
- открытие оригиналов в новой вкладке;
- удаление оригинала и миниатюры с подтверждением операции.

Ограничения размера файлов, разрешения изображений и параметры создания миниатюр задаются в `gallery.php`.

---

## 📄 Структура проекта

| Файл или каталог | Назначение |
|---|---|
| `index.php` | Главная страница с практическими заданиями |
| `includes/functions.php` | Серверная логика основных заданий |
| `gallery.php` | Фотогалерея и обработка изображений |
| `style.css` | Оформление страниц |
| `uploads/` | Оригиналы фотографий |
| `thumbnails/` | Миниатюры фотографий |

Загруженные фотографии и миниатюры исключены из репозитория с помощью `.gitignore`.

---

## 🛠️ Используемые технологии

- **PHP 8** — серверная логика, вычисления, обработка форм и работа с файлами;
- **PHP GD** — обработка изображений и создание миниатюр;
- **HTML5 / CSS3** — структура и оформление страниц;
- **XAMPP / Apache** — локальная серверная среда;
- **Git / GitHub** — контроль версий и хранение исходного кода.

---

## 📱 Адаптивная вёрстка

Основные изменения интерфейса в зависимости от ширины экрана:

- **до 1000 px** — карточки заданий располагаются в одну колонку, фотогалерея — в две;
- **до 760 px** — боковое меню становится горизонтальным;
- **до 480 px** — фотографии располагаются в одну колонку.

Для адаптации используются CSS-медиазапросы, Flexbox, Grid Layout и многоколоночная вёрстка.

---

## 🎨 Особенности интерфейса

- закреплённое боковое меню для перехода между заданиями;
- отдельные блоки вывода результатов вычислений и сообщений об ошибках;
- плиточное расположение фотографий (Masonry Layout) с сохранением их пропорций;
- увеличение фотографий и появление кнопки удаления при наведении.

## 🚀 Локальный запуск

1. Скачать или клонировать репозиторий.
2. Установить XAMPP с PHP 8.
3. Разместить папку проекта под именем `lab7-php` в каталоге `C:\xampp\htdocs` или создать ссылку на неё.
4. Подключить расширение `gd` в файле `php.ini`, если оно отключено.
5. Запустить Apache через XAMPP Control Panel.
6. Открыть приложение в браузере.

[Открыть PHP Lab локально](http://localhost/lab7-php/)

Для загрузки изображений каталоги `uploads` и `thumbnails` должны быть доступны PHP для записи. При необходимости увеличения допустимого размера файлов следует изменить параметры `upload_max_filesize` и `post_max_size` в `php.ini` и перезапустить Apache.

MySQL для работы приложения не требуется.
