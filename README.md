# 💻 PHP Lab

**PHP Lab** — учебное веб-приложение, разработанное в рамках лабораторной работы №7 по дисциплине **«Web-программирование»**.

Приложение объединяет 11 практических заданий по PHP и дополнительную фотогалерею.

---

## ✨ Возможности сайта

- рекурсивное возведение числа в степень;
- отображение текущего времени с правильным склонением слов;
- вывод чисел, кратных трём, с помощью цикла `while`;
- определение чётных и нечётных чисел с помощью цикла `do...while`;
- вывод чисел с помощью цикла `for` без использования тела цикла;
- отображение областей и городов из ассоциативного массива;
- фильтрация городов по начальной букве «К»;
- транслитерация русского текста;
- транслитерация текста с заменой пробелов на подчёркивания;
- калькулятор с четырьмя арифметическими операциями;
- загрузка файлов на сервер;
- проверка корректности введённых данных.

---

## 🖼️ Фотогалерея

В рамках дополнительного задания реализована фотогалерея со следующими возможностями:

- загрузка изображений в форматах JPG, PNG и WEBP;
- проверка типа, размера и разрешения изображения;
- автоматическое создание уменьшенных копий с сохранением пропорций;
- раздельное хранение оригиналов и миниатюр;
- открытие оригинала изображения в новой вкладке;
- удаление фотографий и соответствующих миниатюр с сервера;
- подтверждение удаления;
- отображение сообщений об успешной загрузке и возникающих ошибках.

## 🛠️ Используемые технологии

- **HTML5** — структура страниц;
- **CSS3** — оформление и адаптивная вёрстка;
- **PHP** — серверная логика, вычисления, обработка форм и работа с файлами;
- **HTTP** — передача данных между браузером и сервером;
- **PHP GD** — создание уменьшенных копий изображений;
- **JavaScript** — подтверждение удаления фотографий;
- **XAMPP / Apache** — локальная серверная среда;
- **Git / GitHub** — хранение и публикация исходного кода проекта.

---

## 📱 Адаптивная вёрстка

Основные контрольные точки:

- **1250 px** — изменение размеров бокового меню и карточек;
- **1000 px** — переход к одноколоночному расположению заданий и двум колонкам галереи;
- **760 px** — переход к горизонтальному меню навигации;
- **480 px** — адаптация форм и отображение фотографий в одну колонку.

Адаптивность обеспечивается CSS-медиазапросами, Flexbox, Grid Layout и многоколоночной вёрсткой CSS.

## 🚀 Локальный запуск

1. Скачать или скопировать папку проекта.
2. Установить XAMPP с поддержкой PHP 8 и библиотеки GD.
3. Разместить папку `lab7-php` в каталоге `C:\xampp\htdocs` или создать ссылку на папку проекта.
4. Открыть проект в PhpStorm.
5. Запустить Apache через XAMPP Control Panel.
6. Открыть страницу сайта в браузере.

[Открыть PHP Lab локально](http://localhost/lab7-php/)

Для работы фотогалереи необходимо подключить расширение `gd` в файле `php.ini`, если оно отключено. Папки `uploads` и `thumbnails` должны быть доступны PHP для записи.
